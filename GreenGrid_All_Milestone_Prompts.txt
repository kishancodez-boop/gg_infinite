# GreenGrid India — Complete Milestone Prompt Pack

This pack contains sequential prompts for Milestones 00–17. Use one milestone prompt at a time, in order. Do not paste all prompts into the coding agent in one request.

## How to use
1. Open the GreenGrid India repository folder in your coding agent (Cursor, Claude Code, Codex, OpenCode, or another repository-aware agent).
2. Make sure `memory.md`, `skill.md`, and `FINAL_MASTER_PROMPT.md` are in the repository root. If not, copy them there first.
3. Open `milestone_00_prompt.md`, select all text, and copy it.
4. Paste the prompt into the agent's chat/input box and press Enter/Send. In agent mode, allow it to inspect and edit files.
5. Review its plan and approve any permission prompts for file edits, terminal commands, and dependency installation that you are comfortable allowing.
6. Wait for the agent to finish. Ask it to run the tests/builds and show actual results.
7. Review the summary and verify the app. Then open the next milestone prompt file and repeat.
8. If the agent stops early, send: `Continue implementing the current milestone from the remaining tasks. Do not repeat completed work. Run verification and report actual results.`
9. If an error occurs, paste the full error and ask the agent to fix it before moving on.
10. Keep a backup or Git commit before each major milestone.

## Important operating rules
- Run only one milestone at a time.
- Milestone 00 is discovery/planning and waits for approval before structural changes.
- Milestone 01 onward instructs the agent to implement the selected milestone.
- Do not claim a milestone is complete until its acceptance criteria and verification pass.
- MongoDB credentials and hosting credentials must be supplied securely by you; never paste secrets into public repositories.
- The project intentionally excludes CI/CD and GitHub Actions.
- REA means Reverse Engineering Agent. It must use permitted sources and human review; never bypass access controls.
- Use clearly labelled demo data when live official data is unavailable. Never present demo data as verified national statistics.
- Milestones 12–17 are quality, demo, security, deployment preparation, presentation, and handover work. They do not replace earlier feature milestones.

## Recommended sequence
00 Discovery → 01 Foundation → 02 UI shell → 03 API/data models → 04 Source registry → 05 REA ingestion → 06 Policies/schemes → 07 Solar ROI → 08 Dashboard → 09 RPO tracker → 10 Finance/jobs → 11 Admin/review → 12 Demo mode → 13 QA → 14 Security/data integrity → 15 Manual deployment prep → 16 Presentation → 17 Final acceptance.

## If your coding agent asks what to do
Say: `Implement the current milestone in the repository. Inspect existing work first, preserve working code, execute the changes, run verification, fix failures, and report actual results. Do not just provide instructions.`
